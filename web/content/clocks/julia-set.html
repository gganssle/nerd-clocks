How to read it

Hours and minutes are in the corner. The seconds are the fractal itself. The inset map shows the Mandelbrot set, and its heart-shaped main body (the cardioid) is used as a dial with 60 ticks. The glowing marker moves once around the cardioid per minute, and the big picture is the Julia set for whatever point the marker is on. At :00 the marker is at the notch on the right and the shape is a fat, cauliflower-like blob. At :30 it has reached the pinch on the left, where the set becomes a chain of pinched bubbles.

How it works

Both fractals come from the same one-line rule, applied to complex numbers over and over:

z → z² + c

For a Julia set, c is fixed, and each pixel is a starting value of z. If repeating the rule sends z off to infinity, the pixel is outside the set. The colour records how quickly it escaped, smoothed with the "normalised iteration count" n + 1 − log₂(log |z|) so the bands blend instead of stepping.

The Mandelbrot set is the map of all Julia sets: it colours each value of c by whether z = 0 stays bounded. When c is inside the Mandelbrot set, its Julia set is one connected piece; outside, it shatters into dust.

Why the cardioid?

Points inside the main cardioid are exactly the values of c for which z² + c has an attracting fixed point. A fixed point z* has a multiplier λ = 2z*, and solving for c gives

c = λ/2 − λ²/4

Setting λ = e^{iθ} traces the cardioid's boundary, where the fixed point is neutral: neither attracting nor repelling. Nearby orbits rotate by the angle θ each step, which is why the Julia sets here grow θ-fold spirals and p-armed pinwheels whenever θ/2π is close to a simple fraction p/q. This clock uses |λ| = 0.985, just inside the edge, so every frame is still a connected set.

Nerd note

Every pixel runs up to 220 iterations of z² + c on your GPU, which comes to hundreds of millions of complex multiplications per second. The Mandelbrot set was first plotted in 1978–80 on line printers, as clusters of asterisks.
